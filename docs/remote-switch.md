## Claude Widget 원격 계정 전환

밖에서 폰이나 웹으로 회사 PC의 Claude Code를 쓰다가 사용량이 떨어지면, `/switch` 한 번으로 **대화를 그대로 이어 가면서 다른 계정으로 갈아탈 수 있습니다.**

### 위젯이 하는 일
Claude Widget은 PC에 상주하는 작은 앱입니다. 계정 전환과 관련해서는 세 가지를 합니다.
1. **계정 보관:** 로그인했던 계정들의 로그인 정보를 PC에 암호화해서 보관합니다. (Windows DPAPI, 그 PC의 같은 사용자만 열 수 있음)
2. **계정 교체:** 요청이 오면 Claude Code가 쓰는 로그인 파일을 다른 계정으로 바꿔 끼웁니다.
3. **세션 다시 띄우기:** 하던 대화를 새 계정으로 다시 띄우고, Remote Control을 켜서 원격에서 이어 갈 수 있게 합니다.

### `/switch`는 따로 설치하지 않아도 됩니다
위젯이 켜질 때 Claude Code에 `/switch` 명령을 **자동으로 설치**합니다. 위치는 `~/.claude/commands/switch.md`입니다. 위젯만 깔려 있으면 어느 세션에서든 바로 쓸 수 있습니다.

- `/switch` 입력 → 다른 계정으로 전환 (계정이 2개일 때)
- `/switch 이메일` → 지정한 계정으로 전환

이 명령은 Claude에게 질문하기 전에 PC에서 먼저 실행됩니다. 그래서 **사용량을 다 써서 Claude가 답을 못 하는 상황에서도** 동작합니다.

### 전환할 때 일어나는 일
1. 원격에서 `/switch`를 입력합니다.
2. 위젯이 계정을 바꿉니다.
3. 하던 대화를 새 계정으로 다시 띄웁니다. 대화 기록은 PC에 저장돼 있어서 그대로 이어집니다.
   - **터미널에서 쓰던 세션:** 기존 창은 닫히고, 새 창에서 같은 대화가 이어집니다.
   - **VS Code·데스크톱 앱에서 쓰던 세션:** 기존 세션은 그대로 두고, 대화를 복사한 새 세션이 새 창에서 열립니다.
4. 폰이나 웹에서 **새 계정으로 로그인**한 뒤 세션 목록을 확인합니다. 원래 대화와 **같은 제목**이나 **PC 이름**으로 된 세션이 새로 생겨 있습니다. 거기서 이어 가면 됩니다.

### 알아 둘 점
- **위젯 실행:** 전환이 일어나는 PC에서 위젯이 켜져 있어야 합니다.
- **기존 세션의 원격:** 기존 세션의 원격 연결은 계정이 바뀌는 순간 끊깁니다. 원격은 새로 뜬 세션에서 이어 가면 됩니다.
- **데스크톱 앱 로그인:** Claude 데스크톱 앱의 로그인은 바뀌지 않습니다. 바뀌는 건 Claude Code뿐입니다. (데스크톱 앱은 Claude Code와 로그인 정보를 따로 저장하기 때문)
- **사용량 경고(옵션):** 위젯 설정에서 켜 두면, 사용량이 90%를 넘을 때 Claude가 먼저 "계정 바꿀까요?"라고 물어봅니다.
